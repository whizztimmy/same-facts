Rules make every decision here. The claim finder is a keyword matcher standing in for the model: in production an LLM would pull claims out of listing text, and its output would be one input to the rules, never the decision.

I have no access to Whop's tools or data. Tiers, thresholds and trigger weights are starting values I chose and would calibrate with the team. They are not Whop's terms, and card network dispute thresholds would be checked before quoting any.
